What this demonstration establishes

The training set contains 5 operator-accepted repairs and 19 machine-verified synthetic variants. These variants come from six repair families; they are not 24 independent production incidents. The video is an edited walkthrough of real application captures. River repair, training, checkpoint creation, and held-out evaluation ran live. The UFO extension was built and its tools verified; an authenticated UFO conversation is not shown.

The learned checkpoint depends on the base model and River infrastructure. The checkpoint, dataset provenance, and evaluation record make the training result inspectable. This small evaluation does not establish improvement over the base model.
